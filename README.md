# SmartVax

SmartVax is a web-based vaccine management system that helps citizens find
vaccine information, request vaccinations, and view their vaccination
certificates. Administrators can manage vaccine stock and vaccination events,
review requests, and respond to citizen feedback and contact messages.

## Features

- Citizen registration, sign-in, email verification, and profile management
- Vaccine and vaccination-area information
- Vaccine requests with administrator approval or rejection
- Vaccination certificate viewing
- Administrator tools for vaccine stock, vaccination events, and citizen accounts
- Contact messages, feedback, and administrator suggestions

## Technology

- PHP and Laravel
- Relational database (Laravel migrations are included)
- HTML, CSS, and JavaScript

> The database export containing application data is intentionally not included.
